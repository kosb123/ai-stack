# 비밀과 로컬 데이터

설정 예시에서 `${LOCAL_SECRET}`은 실제 값을 대신한다. 실행 파일이 이 문자열을 자동으로 치환한다고 가정하지 않는다. 실제 설정의 값과 인증 정보는 로컬에서 관리한다.

저장소에 인증 정보, OAuth 토큰, 쿠키, 세션, 개인 키, 메모리, 데이터베이스, 모델, 가상 환경, 로그 또는 백업을 넣지 않는다. `~/.omniroute/storage.sqlite`, `E:/hindsight`의 실제 데이터와 `~/.hindsight`의 실제 설정은 저장소 밖에 둔다.

OAuth 연결이 필요하면 해당 공급자의 공식 로그인 절차로 다시 인증한다. 기존 토큰을 저장소나 채팅으로 복사하지 않는다. 스냅샷 자동 치환과 검사는 보조 수단이다. 커밋과 푸시 전에 파일 목록과 내용을 직접 검토한다.
