# 통합 검증 기록

2026-11-02에 선별한 운영 파일 187개를 가져왔다. 원본과 결과의 SHA-256은 `provenance/sources.json`에 있다. 비밀 제거와 저장소 경로 조정이 있었던 항목은 원본과 결과가 다르며 해당 조정을 기록했다.

## 통과한 검사

| 검사 | 결과 |
| --- | --- |
| 스냅샷 원본 보존, 비밀 제거, 경로 이탈과 경로 겹침 거부, 반복 후처리 | 테스트 8개 통과 |
| 현재 autotune의 오프라인 동작 | 테스트 105개 통과 |
| 대시보드 수집·집계·HTTP 응답 | 테스트 14개 통과 |
| 기존 스택 검증 도구의 안전장치 | 테스트 13개 통과 |
| 저장소 파일·설정·비밀값 패턴 검사 | 발견 0건 |

총 140개 오프라인 테스트다. 실제 모델 추론이나 운영 콤보 변경은 하지 않았다. 현재 운영 소스는 변경하지 않았고, 서비스 재시작·경로 이전·데이터 이관도 하지 않았다.

독립 검토에서 내보내기 출력이 원본을 덮어쓰는 경우와 문서 경로 치환이 적용되지 않는 경우를 재현했다. 두 경우 모두 실패 테스트를 추가한 뒤 수정했고 반복 실행을 확인했다. 모델 정책 때문에 검토자도 GPT-6.1 Terra high를 사용했다. 다른 모델 계열의 독립 판정은 수행하지 못했다.

실제 로컬 자격 증명 후보값을 메모리에서만 비교하는 추가 검사를 수행했다. 이는 검사한 값이 포함되지 않았다는 증거이며, 알려지지 않은 모든 비밀이 없다는 보증은 아니다. 새 비밀값을 추가하기 전에도 같은 검사를 수행한다.

CI는 이 오프라인 검사들을 다시 실행한다. 로컬 검사 결과와 GitHub Actions의 원격 결과는 구분한다.
