# 운영과 검증

## 변경하기

1. 이 저장소에서 변경을 작성하고 검토한다.
2. 실제 배포 대상과 현재 설정의 차이를 확인한다. 예시 파일에는 실제 비밀 값이 없다.
3. 실행 환경 변경에 대해 사용자 승인을 받은 후 대상 파일에 수동으로 반영한다.
4. 영향받는 서비스와 실제 요청을 검증하고 결과를 기록한다.

이 저장소는 실행 경로를 자동으로 동기화하거나 덮어쓰지 않는다. 서비스 재시작이나 기존 디렉터리 이동도 저장소 생성의 일부가 아니다.

## 저장소 검사

`scripts/snapshot.py`는 `snapshot-manifest.json`에 명시된 파일을 수집하고 민감한 값을 치환한다. `--secret-file`은 반복 지정할 수 있다. `scripts/verify_repo.py`는 파일 이름과 내용에서 금지된 항목과 일부 비밀 값 패턴을 검사한다. `tests/test_snapshot.py`는 스냅샷 동작의 테스트다. 각 스크립트의 사용법은 `--help`로 확인한다.

검사 통과는 모든 비밀이 제거됐다는 보증이 아니다. 변경 내용과 추적할 파일을 직접 검토해야 한다. 저장소 검사는 서비스 상태, 실제 라우팅, 도구 호출, Hindsight 메모리 저장을 증명하지 않는다. `skills/verify-hermes-stack/`의 지침을 따르는 실제 환경 검증은 별도로 필요하다.
