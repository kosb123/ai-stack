# OmniRoute 대시보드

OmniRoute 자체 화면보다 보기 쉽고 더 오래 기록을 남기는 개요 화면입니다. 모델별 사용량(입력·캐시·출력·추론 토큰), 남은 할당량, 오류와 쉬운 한글 설명을 한 페이지에 보여 줍니다. OmniRoute는 호출 기록을 약 7일만 보관하지만, 이 대시보드는 자기 DB에 계속 쌓습니다.

## 실행

```bash
cd C:\Users\jun\Desktop\TEST\omni-autotune-dashboard\dashboard
python server.py
```

브라우저에서 http://127.0.0.1:20140/ 을 엽니다. 서버가 시작할 때와 그 뒤 120초마다 OmniRoute DB에서 새 기록을 가져옵니다. 화면은 60초마다 자동으로 새로 고칩니다. 종료는 Ctrl+C입니다.

- Python 3.12 표준 라이브러리만 씁니다. 설치할 것이 없습니다.
- 차트는 CDN의 Chart.js 4.4.1을 씁니다. 인터넷이 없으면 차트만 빠지고 표와 숫자는 그대로 나옵니다.
- 수집만 따로 돌리려면 `python collect.py`, 테스트는 `python -m unittest test_dashboard`입니다.

## 데이터가 있는 곳

- 읽는 곳(읽기 전용): `~/.omniroute/storage.sqlite`. 연결 정보 테이블은 비밀 값(토큰, 키)이 없는 열만 골라 읽습니다.
- 쓰는 곳: `%LOCALAPPDATA%\omni-dash\dash.sqlite` (git에 들어가지 않음). 지워도 다음 수집에서 처음부터 다시 채웁니다.
- 후보 목록: OmniRoute 콤보(순서가 우선순위)와 `omni-autotune\selected_models.json`의 선택.

## 화면 구성

1. 머리말: 기간 탭(24시간 / 7일 / 30일 / 전체), 마지막 수집 시각, 밝은/어두운 화면 전환.
2. 요약 타일: 요청 수, 성공률, 입력·캐시·출력·추론 토큰, 중간 지연. 캐시 비율은 캐시 / 입력 (입력 토큰에 캐시가 포함됨)입니다. 요청 수는 업스트림 시도 단위입니다.
3. 토큰 사용량: 입력·캐시·출력·추론을 쌓은 면적 차트와 오류 수 차트(시간대는 한국 시간).
4. 후보: 콤보별로 순위대로 모델, 24시간 사용 막대, 성공률, 남은 할당량, 연결 상태. autotune이 고른 모델은 아래에 작게 나옵니다.
5. 할당량: 계정과 창별 남은 비율, 리셋까지 남은 시간, 7일 추세 선. 24시간 넘게 갱신되지 않은 값은 접혀 있습니다.
6. 모델별 사용량: 열 제목을 눌러 정렬, 상자에 입력해 거르기. 막대는 표 안에서의 상대 크기입니다.
7. 오류: 종류별 건수 차트, 일별 건수, 그리고 원인 설명과 해결 방법이 붙은 표. 실제 메시지 예시는 "예시"를 눌러 펼칩니다. 오류 본문은 OmniRoute가 지운 뒤에도 이 DB에 남습니다.

오류 분류와 설명은 `catalog.py`에 있습니다. 새 종류의 오류가 "미분류"로 나오면 거기에 규칙을 추가합니다.

## API

`/api/overview`, `/api/timeseries`, `/api/models`, `/api/errors`는 `?range=24h|7d|30d|all`을 받습니다. `/api/quota`, `/api/candidates`, `/api/connections`는 기간과 무관합니다.
